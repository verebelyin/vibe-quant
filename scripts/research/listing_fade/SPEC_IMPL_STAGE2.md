## Calendar-time book (BTC-hedged)
- Events: all pooled records. Days t = day(2023-01-01) .. day(2026-09-30) inclusive.
- Active set A_t = {e : E_e < t ≤ x_e}; n_t = |A_t|. Price p_e(t) = close on the last day ≤ t with data. Event daily return r_e,t = −(p_e(t) / p_e(t−1) − 1) + Σ rate_s over settlements T_{t−1} ≤ s < T_t (T_d = (d+1)·86 400 000). BTC (h9-raw BTCUSDT, h11-funding-a): b_t = c(t)/c(t−1) − 1 − Σ rate_s over the same settlements.
- Target weights: each e ∈ A_t has weight 1/n_t on the short book; BTC weight 1 if n_t ≥ 1 else 0. cost_t = 0.0005 · (Σ_e |w_e,t − w_e,t−1| + |w_btc,t − w_btc,t−1|), weights of day t−1 from A_{t−1} (also for the first day).
- Book return r_t = (1/n_t) Σ_{e∈A_t} r_e,t + b_t − cost_t if n_t ≥ 1, else 0 (flat days stay in the series). No floor.
- `sharpe_252` = mean(r)/std(r, ddof=1)·√252 (ticket wording; the decision number). Report-only: `sharpe_365` (×√365), `ann_return` = mean(r)·365, `unhedged_sharpe_252` (same book without the BTC leg and its costs), `active_days` (n_t ≥ 1).
